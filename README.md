# Student-Performance-Prediction

# Project Overview
This machine learning project predicts student math scores using reading and writing scores

# Dataset
Student Performance Dataset

# Features
* Reading Score
* Writing Score

# Target
* Math Score

# Technologies Used
* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

# Machine Learning Workflow
1. Load dataset
2. Explore data
3. Visualize score distributions
4. Create features and target
5. Split data into training and testing sets
6. Train Linear Regression Model
7. Make predictions
8. Evaluate model performance using R2 score

# Model Used
Linear Regression

# Result
R2 Score: 0.683

# Key Insights
* Students who completed the test preparation course scored higher
* Reading and writing scores are strong predictors for math performance
* Most student scores are between 60 and 80
